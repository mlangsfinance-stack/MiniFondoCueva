# Aviso

**Esto no es asesoramiento financiero ni una recomendación de inversión.**

Este repositorio es material educativo. Enseña un **método para descartar** ideas de trading, no
un sistema para ganar dinero. De hecho, las siete estrategias que trae de ejemplo están **las
siete descartadas**: ninguna es operable y ninguna se propone como tal.

Cosas que conviene tener claras antes de usarlo:

- **Un backtest no es un resultado.** Es una simulación sobre el pasado, con supuestos de coste y
  ejecución que puedes ver y cambiar en `docs/PROTOCOLO.md`. El pasado no se repite.
- **Operar con dinero real conlleva riesgo de pérdida**, incluida la pérdida total del capital.
  Los productos apalancados (CFD, futuros) pueden hacerte perder más de lo depositado.
- **Nadie ha auditado este código.** Se entrega tal cual, bajo licencia MIT (ver `LICENSE`).
  Si lo usas para tomar decisiones, la responsabilidad es tuya.
- **Los números de los informes salen de datos concretos** (NDX diario, 1985-2026, costes de
  2 pb por lado). Con otros datos, otro bróker u otros costes, saldrán otros números.

Si algo de este repo te lleva a poner dinero en riesgo, párate y vuelve a leer
`estrategias/REGISTRO.md`: siete de siete descartadas es el mensaje principal, no un detalle.
